# ChartGen

ChartGen is a local-first chart creation platform for turning tabular data into polished, interactive visualizations without writing code.

## Features

- Spreadsheet-style data entry, editing, CSV/JSON import, paste, validation, samples, undo, and redo
- Project browser with multiple charts per project, search, sort, grid/list views, duplication, and autosave
- Searchable chart editor with live ECharts previews and data mapping
- Customization for typography, axes, legends, grids, labels, palettes, series, and chart-specific controls
- PNG, JPEG, SVG, PDF, and UTF-8 CSV export
- Clipboard image, SVG, data, project-data, and chart-configuration sharing
- Browser Web Share API support with local fallback
- IndexedDB project persistence with localStorage fallback
- Responsive mobile customization drawer and keyboard shortcuts

## Architecture

The app is a Vite + React + TypeScript single-page application. Zustand stores own chart, data, settings, theme, and project state. ECharts renders chart options generated by `src/utils/chartOptions.ts`. Project records are persisted through the storage abstraction in `src/utils/projectStorage.ts`, currently backed by IndexedDB and designed to be replaceable by a server repository later.

## Build

## Deployment

### Vercel

Import the repository in Vercel. Use `npm run build` as the build command and `dist` as the output directory. Configure the platform to rewrite SPA routes to `index.html`.

### Netlify

Set the build command to `npm run build` and publish directory to `dist`. Add a `_redirects` file containing `/* /index.html 200` if history fallback is required.

### GitHub Pages

Build with `npm run build`, publish `dist/` with a Pages workflow, and configure the Vite `base` option to the repository name when deploying under a project subpath. Add an SPA fallback strategy if deep links are enabled.

## Export support

PNG and JPEG use configurable raster dimensions and pixel ratio. SVG uses ECharts' SVG renderer and remains vector-based. PDF includes chart title, subtitle, generated metadata, page size, and orientation. CSV exports UTF-8 data with headers and escaped values.
